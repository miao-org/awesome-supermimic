The 12 fps previews use this FFmpeg conversion:

```sh
ffmpeg -i source.mp4 -filter_complex \
  "fps=12,scale=480:-1:flags=lanczos,setsar=1,split[a][b];[a]palettegen=max_colors=128[p];[b][p]paletteuse=dither=bayer:bayer_scale=4" \
  -loop 0 preview.gif
```

FlatWorld additionally used a `crop` filter before scaling to remove the unused left and right margins.
